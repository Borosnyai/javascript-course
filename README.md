# JavaScript Course

Exercises from a JavaScript beginner course. Each module folder contains the example code and a small `index.html` that loads it. Open the HTML file in a browser and check the console.

| Folder | Topic |
|---|---|
| `module-4-arrays` | Arrays: indexing, `length`, add/insert/remove, concatenate, search, sort |
| `module-5-objects` | Objects: reading and changing properties |
| `module-6-conditionals` | `if` / `else if` statements and a traffic light program with an HTML form (`traffic-light.html`) |

The code examples are partly commented out so that each topic can be tried on its own.
